# ASR21 sparse aesthetic source selection

See [the policy, API, CLI and limitations](../../../docs/rend2-sparse-source-selection-asr21.md).

`run.py --out <fresh-directory>` freezes native source/executable and input
hashes, repeats the owned sparse witnesses and pinned compiled appearance
scenes, and checks that historical core and canonical storage files still match
ASR20. It uses the existing `lightrecon_aesthetic_tool` with the separate
`JKASR21-SPARSE-ENCODED-ASSUMED-MATERIAL-1` protocol and the new
`lightrecon_sparse_test`. No source asset is published.
