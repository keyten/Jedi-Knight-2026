# Rend2 GGX roughness contract and audit

## Public contract

Material-facing and transported roughness is perceptual roughness `r` in
`[0,1]`. The isotropic GGX slope parameter is computed only at the BRDF
boundary:

```
alpha = max(r * r, 0.0025)
alpha2 = alpha * alpha
```

`PerceptualRoughnessToAlpha` is the canonical CPU/GLSL conversion. The alpha
floor bounds the normal-incidence NDF peak to about 50,930, below finite fp16
range and comfortably finite in fp32. `D_GGX` and
`V_SmithGGXCorrelated` accept alpha. Cubemap mip selection, DFG lookup, LTC
lookup, SSR metadata and debug displays accept perceptual roughness.

The canonical NDF is:

```
D(NoH, alpha) = alpha^2 /
    (pi * (NoH^2 * (alpha^2 - 1) + 1)^2)
```

It is normalized by `integral D(h) NoH d_omega_h = 1`. Denominators and input
ranges are guarded against zero/NaN-producing edge cases.

## Smith visibility and Fresnel

Direct GGX, the environment DFG integration, water and the LTC fitter use the
height-correlated Smith-GGX visibility from Heitz 2014. The former linear
square-root approximation was inexpensive but a dense parameter scan reached
about 29.3% relative error at the smooth/grazing limit. Replacing it costs two
square roots in direct-light evaluation; DFG and LTC pay that cost offline.

Standard dielectric/metal and anisotropic-hair GGX use Schlick Fresnel with
explicit `F90 = 1`. The removed `clamp(50 * F0.g, 0, 1)` rule was a historical
low-reflectance grazing heuristic. Normal metal/rough materials already use a
dielectric F0 near 0.04 or base-color metallic F0, so the heuristic only made
unusually low-F0 materials inherit a nonstandard F90. Cloth keeps its separate
Charlie/Ashikhmin model and deliberate no-Fresnel behavior.

## Consumer audit

| Consumer | Domain and decision |
| --- | --- |
| Direct, deluxe, sun and Forward+ | Effective perceptual roughness enters `CalcMaterialSpecular`; standard and hair GGX convert once to alpha. |
| Anisotropic hair | Converts perceptual roughness to alpha before deriving tangent/bitangent alphas. Its masking term remains an isotropic base-alpha approximation, now using the exact correlated form. |
| Cloth/sheen | Charlie/Ashikhmin and the blue DFG channel remain separately fitted in perceptual roughness; they are not silently routed through GGX alpha. |
| Skin and eye | Material-specific diffuse/specular parameters feed the standard GGX path and therefore use the same conversion. |
| Wetness/puddles/runoff | Modify material perceptual roughness before specular AA and before every lighting consumer. |
| Specular AA | Broadens `alpha^2` from normal variance, then converts the effective alpha back to perceptual roughness. |
| Cubemap prefilter | Importance sampling and PDF both evaluate the same `alpha = r^2` GGX distribution. Each generated mip is labelled by perceptual roughness. |
| Runtime cubemap lookup | Uses `perceptualRoughness * ROUGHNESS_MIPS`, matching generation. |
| Environment DFG LUT | Startup CPU integration uses x = perceptual roughness, y = NoV, alpha = r^2, correlated Smith and the Schlick scale/bias decomposition. |
| SSR/SSGI metadata | The normal buffer and temporal history store effective perceptual roughness. Cone width converts it to alpha locally. |
| LTC | Table u is `sqrt(alpha)`, exactly perceptual roughness. Convention-v2 tables were regenerated with correlated Smith. |
| Water | Base and unresolved-wave variance produce perceptual roughness plus explicit alpha; shared GGX functions consume alpha. SSR/cubemap transport stays perceptual. |

The environment DFG LUT and prefiltered cubemaps are generated in memory at
renderer/map initialization. They are therefore rebuilt automatically after
this code change; there is no stock asset for users to regenerate. The GLSL
program cache is source-hashed. The compiled LTC data is explicitly marked
`LTC_GGX_CONVENTION_VERSION 2` and is regenerated by `tools/ltcfit`.

The DFG channel audit and standard-GGX multiple-scattering use are documented
in [rend2-brdf-energy-compensation.md](rend2-brdf-energy-compensation.md).

## Material migration

- Explicit and conventionally discovered ORM/RMO/MOXR maps default to
  `pbrMaterialVersion 2`; their channels are already perceptual.
- Generated AutoPBR, converted legacy specular, spec-gloss and scalar authoring
  default to version 1. Their old effective-alpha value is migrated with
  `newPerceptual = sqrt(oldEffectiveAlpha)` at the shader input boundary.
- `pbrMaterialVersion 1|2` explicitly overrides inference for mods.
- `r_pbrLegacyRoughness 1` (default) preserves stock lobe width;
  `r_pbrLegacyRoughness 0` provides a strict, unmigrated A/B view.

After migration every downstream consumer sees the same public perceptual
domain. Compatibility is an input conversion, not an alternate GGX equation.

## Diagnostics and tests

`r_specularAADebug` displays material perceptual roughness, material alpha,
effective perceptual roughness, added roughness, combined normal variance, or
effective alpha in modes 1 through 6.
`r_autoPBRDebug 3` displays pre-AA material perceptual roughness. SSR debug mode
2 displays the transported effective perceptual roughness. `r_pbrInfo [r]`
prints the active migration state and the conversion of an optional roughness.

`tests/rend2_pbr_contract.cpp` independently checks NDF normalization, finite
behavior, monotonic peak width, GGX sampling/PDF agreement, the legacy
migration mapping and white-furnace bounds across NoV, roughness and F0 values.
The same core checks are available without Boost or a renderer build:

```
c++ -std=c++11 -O2 tools/rend2_ggx_reference.cpp -o rend2_ggx_reference
./rend2_ggx_reference
```
